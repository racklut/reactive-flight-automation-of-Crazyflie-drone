# Reactive flight automation of a Crazyflie drone
Autonomous flight scripts for the Bitcraze Crazyflie 2.1 Brushless. Meant to be used with flow deck v2 &amp; multi-ranger deck.
Test the general functionality of the drone with first-flight before using advanced scripts.

Untouchable --> The drone evades obstacles if they come too close. Otherwise, it remains stationary.
potential field evasion --> The drone flies forward, avoiding obstacles along the way.
Reactive flight path --> The drone flies along preset waypoints and avoids obstacles along the way.

For more information please visit: https://github.com/bitcraze
